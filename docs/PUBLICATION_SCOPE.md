# 公开范围

本仓库从原实验目录中按允许列表整理代码。原始目录保留在本地，不与公开仓库自动镜像。

## 可以提交

- 已审查的 Python 源码、测试、依赖声明和必要的服务配置。
- 不含实验记录的运行说明、接口说明和来源说明。
- 完全新编写的小型合成样例，以及测试中动态生成的临时数据。
- 空值环境变量模板。服务地址、口令和模型选择由使用者自行填写。

## 保留在本地

- 实验用真实数据、完整招聘文本、原始图像、表格、标注和向量索引。
- 本地 API 凭据、服务工作区信息、私人地址和机器路径。
- 训练权重、检查点、缓存、数据库、预测文本、运行日志和追踪记录。
- 论文正文、图表、审稿意见、投稿材料、课程报告和合作分工材料。
- 原 Git 历史、嵌套第三方仓库和未经确认的上游源码副本。

## 新增代码时

1. 先在公开仓库中创建分支，选择具体源文件迁移。不要将整个实验目录拖入仓库。
2. 将路径与凭据改为显式配置；检查 notebook 输出、注释、测试夹具和文档是否夹带真实内容。
3. 补充不依赖真实材料的最小验证，并说明尚未验证的外部依赖。
4. 将明确选择的文件加入暂存区，运行 `python tools/check_publication.py --staged` 和相关测试，检查 `git diff --cached` 与暂存文件清单。无参数的严格全目录检查用于干净发布快照。
5. 通过 Pull Request 保存变更与验证记录。

公开检查规则保存在 `publication-policy.json`。扫描器不打印命中原文，避免将敏感值再次写入日志。启发式检查无法证明所有文件均不含敏感内容，允许列表与人工审查仍是发布边界的一部分。
