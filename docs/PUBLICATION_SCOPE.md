# 公开与维护范围

当前分支仅维护项目索引、设计说明、来源与维护检查工具，不承载可安装研究项目。原来两个项目的源码已转到独立仓库；旧版本仍在 Git 历史中保留。

## 可以提交

- 指向独立仓库的导航和已核对的源码、文档及测试链接。
- 无私人信息的工程设计解释、运行边界、来源和迁移说明。
- 检查索引结构、文档链接和公开边界所需的维护脚本及测试；夹具仅在测试时动态生成。
- 仓库级只读 CI 配置。

## 项目修改的去向

README 列出的 canonical repository 是每个项目唯一的当前维护入口。源码、依赖、配置、训练与推理代码、项目数据样例及项目回归测试均提交到相应仓库，不复制回本索引。历史快照只用于追溯。

真实数据、论文及审稿材料、个人证明文件、API 凭据、私人地址、模型、检查点、数据库、运行输出和缓存继续保留在本地。索引维护不导入原始实验目录或私人 Git 历史。

## 发布检查

`publication-policy.json` 不允许 `projects/` 目录。`tools/check_index.py` 同时核对当前跟踪文件清单与文档链接；公开扫描使用工作目录或实际 Git index blobs，暂存模式读取已暂存策略。新增文件先明确暂存，再检查变更，通过 Pull Request 与 CI 合并。

扫描不打印命中原文，也不能证明历史、来源、许可或所有内容均无敏感信息。维护者仍需核对提交范围和文字依据。
